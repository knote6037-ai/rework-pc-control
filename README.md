# Rework PC Control — Bentley Edition

## Прозрачность и автозапуск

Подложки блока управления и фиолетовой Astra Limits полупрозрачны: через них виден живой фон, а текст и кнопки остаются чёткими.

На этом компьютере включён автозапуск Rework после входа в Windows. Он использует ярлык текущего пользователя в папке «Автозагрузка», без прав администратора. Окно открывается автоматически; повторный запуск активирует существующий экземпляр. Для повторной настройки после переноса папки запустите `Install-Autostart.ps1`, для отключения — `Disable-Autostart.ps1`. Модуль CPU по-прежнему подключается отдельно кнопкой датчиков.

## Astra Limits внутри PC Control

Интеграция гибридная: актуальный интерфейс с поворотом работает в Qt Quick/QML, а адаптер Astra Limits написан на **C# / .NET Framework**. Фиолетовая панель встроена под компактным выключением. Модуль `limits/AstraLimitsBridge.exe` должен находиться рядом с остальной поставкой; исходник и скрипт сборки лежат в той же папке проекта. Для чтения лимитов ему не нужны права администратора.

Справа под компактным управлением выключением находится Astra Limits: реальный остаток лимитов Codex, полосы остатка, время до сброса и ручное обновление. Автообновление выполняется раз в минуту через установленный локальный Codex с существующим входом. Лимиты не подменяются значением 100% после наступления времени сброса: приложение ждёт ответ сервера. Ошибки обновления помечают последние показания как старые.

Используется только чтение `account/rateLimits/read` и начальная инициализация, без запуска модели и без действий со сбросами или покупкой кредитов. Источник: [официальная документация OpenAI App Server](https://learn.chatgpt.com/docs/app-server). Отдельный виджет Astra Limits можно оставить запущенным независимо от PC Control.

Нативное приложение для 64-разрядной Windows: C++ отвечает за таймер, датчики и управление компьютером, Qt Quick/QML — за чёрно-белый интерфейс, часы и анимацию.

## Bentley Edition — версия 4

Интерфейс помещается в одном окне без вертикальной прокрутки. Левая панель последовательно поворачивается между тремя сторонами: **часы → температуры CPU/GPU → ассистенты → часы**. Для переключения нажмите свободную область панели, кнопку следующей стороны или выберите нужную сторону внизу. Управление выключением справа остаётся на месте.

На стороне ассистентов кнопки открывают установленные **Codex**, **Claude** и **DeepSeek Harness**. Запуск выполняется Windows; текст в чаты не отправляется. Если приложение не найдено или Windows отклонила запуск, выводится сообщение. Клик по кнопке приложения не поворачивает панель.

Вдохновение для механики: [Bentley Rotating Display](https://www.bentleymotors.com/en/models/technology.html). Чёрно-белые материалы, движущийся свет, крупный циферблат и заметные блики сохранены.

## Материалы и анимации

В обновлении **3.1** фон получил движущиеся серебристые волны, световые поля и частицы. По краям панелей проходят отражения, кнопки реагируют на наведение, интерфейс плавно появляется. Блики на камнях стали крупнее и чаще; световой проход по граням повторяется примерно каждые пять секунд. Часовая и минутная стрелки расширены и получили контрастную окантовку.

Первый экран сочетает тёмную часовую панель и светлое управление. Циферблат выполнен как серебристые скелетон-часы с камнями: стрелки показывают текущее время, грани мерцают отдельно, свет слегка реагирует на курсор. Включённую анимацию приложение приостанавливает, когда часы не видны.

На стороне температур отображаются реальные температуры CPU и GPU, нагрузка и история последних измерений. Источники данных продолжают обновляться при переключении на другую сторону.

GPU NVIDIA читается через установленный драйвер. Температура CPU Package читается отдельным модулем на LibreHardwareMonitor 0.9.6 и PawnIO 2.2.0. В карточке CPU нажмите **Подключить датчик CPU** и подтвердите запрос Windows. Если PawnIO ещё не установлен, кнопка предложит открыть официальный подписанный установщик из папки sensors; после установки подключите датчик ещё раз.

Основное приложение работает без прав администратора. Повышенные права нужны только модулю чтения CPU. Он завершается после выхода из своего экземпляра Rework; после нового запуска датчик CPU может потребовать повторного подключения. Настройки вентиляторов, напряжения и частоты не меняются.

Данные обновляются примерно раз в две секунды. Если источник не отвечает или данные устарели, отображается прочерк, а не вымышленная температура. На этом ПК подтверждены Intel Core i5-14400F (CPU Package) и NVIDIA GeForce RTX 5060.

Детализированный циферблат создан встроенным ImageGen по референсу пользователя; живые стрелки и эффекты реализованы в QML. [PNG-ассет](assets/diamond-dial.png), [промпт и происхождение](assets/ASSET-NOTES.md).

## Запуск

Откройте **app/ReworkPCControl.exe** либо ярлык **Rework PC Control** на рабочем столе. Для создания или обновления ярлыка запустите **Install-DesktopShortcut.ps1**. После перемещения папки приложения запустите этот скрипт ещё раз.

Сохраняйте всю папку **app** вместе с EXE: внутри находятся необходимые библиотеки Qt, плагины и среда MinGW. Установленный Qt Creator для обычного запуска готового приложения не требуется. Часы, датчики и таймер работают офлайн; для обновления лимитов Astra требуется соединение Codex с сервисом.

Если рядом сохранена прежняя версия Rework на C#/WebView2, новая версия находится в отдельной папке **ReworkPCControl-Qt**. Ярлык с тем же именем переключается на новую версию после запуска установочного скрипта.

## Управление

- **Открыто** — компьютер работает, выбран рабочий режим пространства.
- Первое нажатие **Выключить** или **Закрыто** показывает вопрос **Точно закрыть?**. Отсчёт ещё не запускается.
- Повторное подтверждение запускает отсчёт. По умолчанию выбрано **10 минут**; допустимы целые значения **от 1 до 180 минут**. Вопрос подтверждения действует 30 секунд.
- Изменение выбранного времени во время отсчёта сохраняет предпочтение. Чтобы заменить активный отсчёт новым, снова подтвердите его запуск.
- **Отменить выключение** или возврат в **Открыто** отменяют таймер приложения.
- **Escape** закрывает вопрос подтверждения. Если уже шёл отсчёт, он сохраняется до отдельной отмены.

Подсветка комнаты пока **только отображает выбранный режим**. Физические лампы и лента приложением не управляются.

## Таймер и восстановление

Логика находится в C++, а не в QML. Во время работы используется монотонное время: отсчёт не ускоряется при ручном изменении часов Windows.

Подтверждённый активный таймер сохраняется в **QSettings** и может восстановиться после перезапуска приложения **в рамках той же загрузки Windows**, если его срок ещё не прошёл. Для этого проверяется идентификатор загрузки Windows. Повреждённые, неподтверждённые, просроченные или относящиеся к прошлой загрузке данные не запускают выключение.

Полный выход через пункт **Выйти и отменить таймер** отменяет отсчёт. Сон и гибернация также отменяют его: после пробуждения компьютер не выключается неожиданно. Если приложение не работало в момент запланированного завершения, оно не выключит ПК задним числом при запуске.

Крестик окна скрывает приложение в трей рядом с часами Windows. Там можно снова открыть окно, отменить отсчёт или полностью выйти. Повторный запуск приложения открывает уже работающий экземпляр.

В конце отсчёта выполняется один обычный запрос Windows **ExitWindowsEx(EWX_POWEROFF)**. Флаги принудительного закрытия программ не используются. Программы с несохранёнными файлами могут задержать выключение; сохраните работу заранее. После передачи запроса Windows отмена выполняется на системном экране Windows, если он показан.

Приложение не использует системный таймер `shutdown /t` и команду `shutdown /a`, поэтому не отменяет таймеры выключения, заданные другими программами. Ошибки Windows показываются в интерфейсе; автоматических повторных попыток выключения нет.

## Визуальные эффекты

Внутри интерфейса используются серебристые материалы, шейдерные эффекты и анимированные блики на камнях. Системный Acrylic включается через DWM на совместимых версиях Windows 11. Окно имеет собственную рамку и элементы управления.

Системное размытие зависит от версии Windows, видеодрайвера, режима энергосбережения и системной настройки прозрачности. На неподдерживаемой системе сохраняется интерфейс с собственными эффектами. Плавность зависит от видеокарты и частоты экрана; заданная частота кадров не гарантируется.

## Безопасная демонстрация

Параметр **--demo** включает демонстрационный режим с отдельными настройками и видимой отметкой. В нём настоящий запрос выключения не вызывается даже при завершении отсчёта. Используйте этот режим для проверки оформления и кнопок.

## Сборка

Нужен кит **Desktop Qt 6.12.0 MinGW 64-bit**, **CMake**, **Ninja** и **Qt Shader Tools**. Проект предназначен для MinGW, а не для MSVC-кита Visual Studio. В Qt Creator откройте **CMakeLists.txt** и выберите установленный Desktop Qt 6.12.0 MinGW 64-bit.

Для автоматической сборки запустите **Build.ps1** в Windows PowerShell. По умолчанию он использует:

- Qt: `C:\Qt\6.12.0\mingw_64`;
- компилятор: установленный MinGW 64-bit из `C:\Qt\Tools`;
- CMake: `C:\Qt\Tools\CMake_64\bin\cmake.exe`;
- Ninja: `C:\Qt\Tools\Ninja\ninja.exe`.

Можно передать параметры `-QtKit`, `-CompilerDirectory` и `-BuildDirectory`, если инструменты находятся в другом месте. Скрипт меняет PATH только для своего процесса и восстанавливает его после сборки. Промежуточные файлы размещаются вне папки проекта. В исходном рабочем пространстве это **work/qt-build**.

Сначала собираются приложение и проверки, затем запускается **ctest**. Только после успешных проверок EXE и зависимости копируются в **app** с помощью **windeployqt**. Перед обновлением сборки полностью закройте запущенный Rework через меню значка в трее.

## Исходники и проверки

- **src/ControlModel.h/.cpp** — состояние, подтверждение, отсчёт, отмена и восстановление.
- Остальные файлы **src/** — Windows-окно, системный трей, сохранение настроек и запрос выключения.
- **qml/** — интерфейс и часы.
- **shaders/** — исходники визуальных эффектов.
- **tests/** — проверки логики с подставным временем и безопасным обработчиком выключения.

Тесты не вызывают реальное выключение ПК. Они проверяют подтверждение, ограничения времени, отмену, перезапуск отсчёта, восстановление, ошибки Windows и независимость от перевода часов.

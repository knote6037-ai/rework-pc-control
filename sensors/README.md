# Датчики Rework PC Control

Видеокарта NVIDIA читается напрямую через `nvidia-smi.exe`, установленный вместе с драйвером. Rework выполняет запрос каждые две секунды без консольного окна и без блокировки интерфейса. Температура и загрузка не имитируются.

Для CPU используется отдельный **ReworkSensorHost.exe** и библиотека **LibreHardwareMonitor 0.9.6**. Модуль включает только чтение датчиков процессора. Температура берётся из **CPU Package**, **Core Max** или наиболее горячего доступного ядра. Температуры материнской платы и ACPI не выдаются за температуру CPU.

## Подключение CPU

В основном приложении нажмите **Подключить датчик CPU**. Если PawnIO ещё не установлен, приложение предложит открыть официальный установщик. После завершения установки нажмите кнопку ещё раз и самостоятельно подтвердите запрос Windows на запуск модуля датчиков. Основное окно Rework продолжает работать без прав администратора.

В комплекте находится официальный **PawnIO 2.2.0**, скачанный с [репозитория автора](https://github.com/namazso/PawnIO.Setup/releases/tag/2.2.0). Подпись установщика проверена при подготовке: **Valid, namazso.eu / namazso**. Rework не устанавливает драйвер незаметно и не меняет настройки безопасности Windows.

Модуль работает, пока запущен экземпляр Rework, который его подключил. После полного закрытия Rework модуль завершает работу. При следующем запуске доступ к CPU подключается кнопкой заново.

Модуль передаёт результаты через локальный файл `%LOCALAPPDATA%\Rework\ReworkPCControl\Sensors\cpu.json`. Запись атомарная. Значения старше восьми секунд, повреждённые файлы, отсутствующие, бесконечные или неправдоподобные температуры не показываются как действующие данные. При недоступности датчика выводится `—`.

Датчики не управляют вентиляторами, напряжениями, разгоном или питанием; сетевые порты не открываются. Загрузка CPU читается обычным Windows API и доступна независимо от температурного модуля.

## Сборка

`BuildSensorHost.ps1` пересобирает вспомогательный EXE встроенным компилятором .NET Framework. SDK .NET не требуется. Для запуска нужна .NET Framework 4.8, входящая в современные Windows 10/11.

## Сторонние компоненты

LibreHardwareMonitor: [исходники и лицензии](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor/tree/v0.9.6). Взяты неизменённые DLL из [официального выпуска v0.9.6](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor/releases/tag/v0.9.6). Основная библиотека лицензирована по MPL-2.0. У зависимостей сохранены собственные лицензии; тексты размещены в папке `licenses`.

PawnIO: [официальные выпуски](https://github.com/namazso/PawnIO.Setup/releases), [исходники](https://github.com/namazso/PawnIO). Установщик работает интерактивно и показывает собственное соглашение.
